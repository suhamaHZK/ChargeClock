# Charge Clock（充電時計）— 要件・設計メモ

最終更新: 2026-09-16（Asia/Tokyo）  
フェーズ: 実装中（ユーザー・参謀許可済み）

## 1. プロダクト概要

| 項目 | 内容 |
|------|------|
| 表示名 | 充電時計 / Charge Clock |
| applicationId | `com.kmmm_engineering.chargeclock` |
| GitHub（予定） | `suhamaHZK/ChargeClock`（private・未作成） |
| 最低対応 | Android 10（API 29）以上 |
| targetSdk | 実装時に現行推奨 |
| 課金・広告 | なし |

充電中向けの全画面デジタル時計。日付・時刻・バッテリー残量を大きく表示する。

## 2. 画面構成

### 2.1 メイン（時計）画面

- 没入型全画面（ステータスバー・ナビゲーションバー非表示）
- 背景 `#000000`
- 文字色: デフォルト白。設定で変更可（カラーピッカー）
- 中央付近に大きく:
  1. 日付行（曜日を常時含む）
  2. 時刻行（秒は設定でオン／オフ、デフォルトオン）
  3. バッテリー残量（%）。充電中は稲妻アイコンを%の左に表示
  4. その下に10ブロックの残量バー（各≈10%。`floor(level/10)` 塗り、100%は全塗り）。色は文字色。表示サイズに比例
- スケッチ: `design/battery-ui-sketch.svg`
- OLED焼け対策: 表示ブロック全体を数分おきに数px〜十数pxずらす
- 初回起動のみ: 「ダブルタップで設定画面を表示」を出す（ダブルタップ成功まで）

### 2.2 輝度挙動

| タイミング | 挙動 |
|------------|------|
| アプリ起動・フォアグラウンド復帰 | 待機輝度（設定値・極小寄り）を適用 |
| 画面タップ（シングル） | システム相当の輝度に5秒間だけ戻す → 再度待機輝度 |
| ホーム／他アプリへ | Window輝度を解除し、システム輝度に戻す |

※ システム全体の輝度設定は書き換えない（Window の `screenBrightness` 想定）。

### 2.3 スリープ

- デフォルト: アプリ実行中はスリープしない（`KEEP_SCREEN_ON` 相当）
- 設定で「自動スリープする」に切り替え可

### 2.4 設定への導線

1. ダブルタップ
2. スライダー表示（誤操作防止）
3. 右方向へスライド完了で設定画面へ

スライダーUI: 丸みのあるトラック＋白サム（`design/unlock-slider.svg`）。文言は **「スライドで設定 >>」**（確定）

### 2.5 設定画面

一覧で変更。保存は即時（または戻る時）でよい（実装時に決定可）。

## 3. 設定項目一覧

| 項目 | 選択肢／型 | デフォルト |
|------|------------|------------|
| 言語 / Language | System / English / 日本語 | System |
| 待機時の輝度 | スライダー等（低めレンジ） | 極小寄り |
| 文字色 | カラーピッカー | 白 `#FFFFFF` |
| Discord Webhook URL | 文字列 | 空 |
| Discord通知（放電中） | OFF, 5%, 10%, … 100%（5%刻み） | OFF |
| Discord通知（充電中） | OFF, 5%, 10%, … 100%（5%刻み） | OFF |
| 強制横表示 | OFF / 右 / 左 | OFF |
| 表示サイズ | スケール（時刻・日付・残量まとめて） | 標準 |
| 12/24時間 | 12時間 / 24時間 | **24時間** |
| 秒の表示 | オン / オフ | **オン** |
| 日付形式 | YYYY/MM/DD, MM/DD/YYYY, DD/MM/YYYY | YYYY/MM/DD |
| 月の形式 | 01等 / Jan等 | 01等 |
| 曜日の形式 | Mon等 / 月等 | Mon等 |
| 充電器を外したら自動終了 | オン / オフ | オフ |
| 起動中の自動スリープ | する / しない | **しない** |

### MVP対象外

- 充電開始時の自動起動（設定にも出さない。後続版で再検討）

## 4. Discord通知

| 条件 | 内容 |
|------|------|
| 放電中 | 残量 ≤ 閾値 になったとき通知 |
| 充電中 | 残量 ≥ 閾値 になったとき通知 |
| 発火 | 閾値を**またいだ瞬間に1回だけ**（同じ側にいる間は再送しない） |
| 言語 | アプリ言語設定に合わせる想定 |

Webhook URL・実トークンは引継書やリポジトリに書かない。

## 5. 権限・技術メモ（設計）

- `INTERNET`（Discord Webhook）
- バッテリー状態: sticky broadcast / `BatteryManager`
- 没入モード: システムバー非表示
- 充電器切断で終了: 充電状態リスナー
- 輝度: Activity Window の `screenBrightness`（0〜1）
- minSdk 29 / targetSdk は実装時に現行推奨
